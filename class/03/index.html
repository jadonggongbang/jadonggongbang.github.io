화면 한 바퀴: 채팅·프로젝트·아티팩트·설정

Claude 화면에서 처음에 알아 둘 곳들. 채팅, 시크릿 채팅, 프로젝트, 아티팩트, 설정이 각각 무슨 일을 하는 곳인지 짚어 드려요.

월요일마다 "저는 마케팅팀이고, 보고는 다섯 줄로…"를 또 붙이고 있다면, 그 수고를 덜어 주는 메뉴가 왼쪽에 이미 있어요. 있는 줄 몰랐을 뿐이에요.
오늘은 그런 곳 몇 군데만 같이 걸어 볼게요. 외우지 않으셔도 돼요. '이런 게 있었지' 정도만 남으면, 필요한 날 이 글로 돌아오시면 돼요.

Claude 화면은 업데이트가 잦아서 버튼 위치나 이름이 자주 바뀌어요. 화면 언어를 한국어로 해 두면 메뉴 이름도 한국어로 보여요. 아래 영어 이름은 공식 도움말 표기예요. 화면이 다르면 비슷한 이름을 찾으시면 돼요. 버튼이 안 보여서 헤매는 시간이 그만큼 줄어요.

1. 채팅: 그냥 대화하는 곳

가운데 입력창이 전부예요. 여기에 쓰면 대화가 시작되고, 지난 대화는 왼쪽 목록에 쌓여요.

  • 입력창 옆 + 버튼: 파일이나 사진을 붙여요. 엑셀, PDF, 스크린숏 다 돼요. 화면을 말로 설명하는 대신 스크린숏 한 장이면 돼요.
  • 대화 하나 = 일 하나: 회의 메모를 정리하던 채팅에서 갑자기 자소서를 물으면 앞 내용이 섞여요. 일이 바뀌면 새 채팅을 여세요. (11강에서 더)

이럴 때 써요

메일 하나 다듬기, 면접 예상 질문 뽑기, 여행 짐 목록처럼 한 번 하고 끝나는 일이요. 이런 일은 채팅으로 충분하고, 다른 메뉴를 열 필요가 없어요.

2. 시크릿 채팅: 기록을 안 남기고 싶을 때

공식 도움말 기준으로 이렇게 써요.

  • 새 채팅 화면 오른쪽 위 유령 모양 아이콘을 누르면 시크릿 채팅이 돼요.
  • 켜지면 화면 테두리가 검게 바뀌고 왼쪽 위에 "Incognito chat"이라고 떠요.
  • 이 대화는 채팅 목록에도, Claude의 기억에도 안 남아요. 다음 대화에 이 이야기가 끌려 들어오지 않아요.
  • 대신 닫으면 다시 못 열어요. 프로젝트 안에서는 쓸 수 없고요.

이럴 때 써요

  • 친구 고민 상담 내용 정리처럼, 남겨 두기 애매한 이야기
  • '기억 없는 상태'에서 답이 어떻게 나오는지 시험해 볼 때

다만 공식 도움말에는 시크릿 채팅도 기본 30일은 보관된다고 적혀 있어요. 목록에 안 보일 뿐, 바로 지워지지는 않아요. 그러니 시크릿이어도 주민번호나 계좌처럼 정말 민감한 정보는 넣지 마세요.

3. 프로젝트: 같은 설명은 한 번만

매번 "저는 마케팅팀 신입이고, 우리 회사는 이런 곳이고…"를 붙이고 계시다면 프로젝트를 쓸 때예요.

프로젝트는 자료와 지침을 넣어 둔 방이에요.

  • 지식(knowledge): 파일이나 글을 올려 두면, 그 프로젝트 안의 모든 채팅이 그걸 참고해요.
  • 지침(instructions): "답은 항상 존댓말로", "표로 줘" 같은 규칙을 한 번 적어 두면 계속 지켜요.
  • 무료는 프로젝트 5개까지예요. (공식 도움말 기준)

예시로 보면

프로젝트 이름넣어 둘 자료지침 한 줄
주간 보고지난 보고 두세 개"이 모양 그대로, 5줄 넘지 마"
졸업 프로젝트과제 안내문, 조원 역할표"마감 기준으로 할 일을 거꾸로 잡아 줘"
이사 준비계약서, 체크리스트"날짜 있는 건 날짜순으로"

지침 쓰는 법은 9강에서 제대로 다룰게요. 오늘은 '자주 하는 일은 방을 하나 만들면 되는구나'만 가져가세요.

4. 아티팩트: 결과물이 옆 창에 뜨는 것

긴 문서나 표, 작은 도구를 부탁하면 대화 오른쪽에 결과물이 따로 뜰 때가 있어요. 그게 아티팩트예요.

공식 도움말 기준으로는 이래요.

  • 보통 15줄이 넘고 그것만으로 완성된 결과물일 때 아티팩트로 만들어요.
  • 무료에서도 돼요.
  • 왼쪽 메뉴 Artifacts 칸에서 지금까지 만든 걸 모아 볼 수 있어요. 지난주에 만든 체크리스트를 찾느라 채팅을 뒤질 필요가 없어요.
  • 처음 만든 건 나만 봐요. 공유는 따로 해야 해요.
  • 결과물에 오류가 나면 근처에 "Try fixing with Claude" 버튼이 떠요. 누르면 고쳐 달라고 할 수 있어요.

이럴 때 아티팩트가 편해요

  • 자기소개서처럼 여러 번 고쳐 가며 다듬는 문서. 고친 판이 한 창에 쌓여서 어느 판이 최신인지 헷갈리지 않아요.
  • "버튼 누르면 점심 메뉴를 골라 주는 거 만들어 줘" 같은 작은 도구

안 뜰 때

설정에서 파일 만들기 기능이 꺼져 있으면 아티팩트가 안 만들어져요. 공식 도움말은 Settings > Capabilities의 "Cloud code execution and file creation"(새 화면에서는 "Create and edit files")을 켜라고 안내해요.

5. 설정: 처음에 한 번만 열어 볼 곳

설정은 내 이름이나 프로필 메뉴 안에 있어요(위치는 화면 버전마다 조금 달라요). 처음엔 아래만 한 번 열어 보면 돼요. 한도에 걸리거나 기능이 안 될 때 어디부터 볼지 알게 돼요.

사용량 (Usage)
5시간 한도와 주간 한도가 막대로 보여요. 2강에서 본 그 막대예요.

기능 (Capabilities)
아티팩트·파일 만들기 같은 기능을 켜고 끄는 곳이에요. 아티팩트가 안 뜨면 여기부터 보세요.

기억 (Your Claude / Memory)
Claude가 지난 대화에서 나에 대해 기억하는 걸 관리해요. 공식 도움말 기준으로 기억 만들기를 켜고 끄거나, 잠시 멈추거나(Pause), 초기화(Reset)할 수 있어요. 내가 말한 적 없는 걸 Claude가 안다 싶으면 여기를 보시면 돼요. 무엇이 남고 무엇이 안 남는지는 10강에서 자세히 볼게요.

하나 더. 지난 채팅을 Claude에게 "그때 그 대화 찾아 줘"라고 시키는 기능은 공식 도움말 기준 유료 요금제만 돼요. 무료면 왼쪽 목록에서 직접 찾으셔야 해요.

6. 따라 해 보기 (5분)

  1. 새 채팅을 열고 오른쪽 위 유령 아이콘을 눌러요. 테두리가 검게 바뀌면 성공이에요. x로 닫아요.
  2. 왼쪽에서 프로젝트를 하나 만들어요. 이름은 "연습"이면 돼요.
  3. 그 프로젝트 지침 칸에 이렇게 적어요.
답은 항상 세 줄 안으로 해 줘. 마지막 줄은 내가 할 일 하나로 끝내.
  1. 그 프로젝트 안에서 아무거나 물어보세요. 예를 들어 "이번 주에 운동 시작하려면 뭐부터 해?"
  2. 이렇게 보이면 성공: 답이 세 줄이고, 마지막 줄이 할 일 하나예요.

이 5분이 지나면, 다음부터 같은 설명을 다시 붙이지 않아도 되는 방이 하나 생겨요.

7. 막히는 곳, 그리고 왜 그런지

"유령 아이콘이 안 보여요."
프로젝트 안에서 새 채팅을 여셨을 수 있어요. 시크릿 채팅은 프로젝트 밖에서만 돼요.

"아티팩트가 안 떠요."
결과가 짧으면 그냥 대화창에 써 줘요. 아니면 설정의 파일 만들기 기능이 꺼져 있을 수 있어요. 꼭 받고 싶으면 "별도 문서로 만들어 줘"를 붙이세요.

"프로젝트 지침을 안 지켜요."
지침이 길고 여러 개면 몇 개를 놓칠 때가 있어요. 제일 중요한 것 하나만 남기고 다시 해 보세요. 지침 쓰는 요령은 9강에서 다뤄요.

"메뉴 이름이 글이랑 달라요."
업데이트가 잦아서 그래요. 비슷한 이름을 찾거나, Claude에게 "설정에서 기억 끄는 곳이 어디야?"라고 직접 물어보셔도 돼요.

8. 숙제 하나

이번 주에 같은 설명을 두 번 넘게 붙인 일이 있었는지 떠올려 보세요. 있다면 그게 첫 프로젝트 후보예요. 이름만 적어 두세요.

첫 프로젝트: ______

9강에서 이 이름으로 방을 실제로 만들어요.

오늘 거 한 장으로

곳무슨 일을 하는 곳언제
채팅대화 하나 = 일 하나한 번 하고 끝나는 일
시크릿 채팅목록·기억에 안 남아요 (30일 보관은 돼요)남기기 애매한 이야기, 시험해 볼 때
프로젝트자료 + 지침을 넣어 둔 방. 무료 5개같은 설명을 두 번 넘게 할 때
아티팩트결과물이 옆 창에 따로 떠요여러 번 고칠 문서, 표, 작은 도구
설정사용량, 기능 켜고 끄기, 기억 관리처음에 한 번, 한도에 걸렸을 때
