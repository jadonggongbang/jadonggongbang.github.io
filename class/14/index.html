CLAUDE 교실 · 14강 · 3부 · Cowork로 일 맡기기

폴더 하나 맡겨서 정리시키기

엉망인 폴더 하나를 Cowork에게 맡기는 네 걸음을 정리했어요. 민감한 파일 먼저 빼기, 계획 받기, 지우기 없이 옮기기만 시키기, 되돌리기 목록 남기기예요. 지어낸 바탕화면 파일 17개로 돌려 본 결과와 막히는 곳까지 담았어요.

서랍을 정리하다 보면 꼭 어디 열쇠인지 모르는 열쇠가 하나 나와요. 버리면 속이 시원하겠지만, 그게 하필 자전거 자물쇠 열쇠면 곤란해요. 그래서 우리는 그런 걸 '모르는 것' 칸에 따로 둬요. 정리를 잘한다는 건 잘 버리는 게 아니라, 모르는 걸 함부로 버리지 않는 거예요.

13강에서 Cowork가 뭔지 봤어요. 오늘은 진짜로 폴더 하나를 맡겨서 정리시켜요. 이걸 알면 바탕화면이나 다운로드 폴더를 붙잡고 있던 주말 한 시간이 몇 분으로 줄어요. 그리고 정리하다가 귀한 파일을 잃어버리는 일도 막을 수 있어요.

1. 한 줄로: 빼고, 계획 받고, 옮기기만, 목록 남기기

폴더 하나를 맡길 때는 이 네 걸음이에요.

걸음하는 일왜
① 빼기민감한 파일은 내 손으로 먼저 빼요맡긴 폴더 안의 파일은 Claude가 열어 봐요
② 계획 받기아무것도 옮기지 말고 계획만 받아요계획에서 잘못된 걸 고치는 게 제일 싸요
③ 옮기기만지우기 없이 옮기기·이름 바꾸기만 시켜요옮긴 건 되돌릴 수 있지만, 지운 건 어려워요
④ 목록 남기기'원래 위치 → 새 위치'를 파일로 적게 해요마음에 안 들면 이 목록으로 되돌려요

12강 3점표로 보면, 폴더 정리는 ③번 '되돌릴 수 있나'를 내가 1점으로 만드는 일이에요. 지우지 않고 목록을 남기면, 틀려도 되돌릴 수 있는 일이 돼요.

2. 시작 전에: 이 두 가지만 확인해요

요금제: Cowork는 유료 요금제(Pro, Max, Ultra, Team, Enterprise)만 돼요. 내 컴퓨터 폴더를 만지려면 데스크톱 앱(Mac, Windows)을 열어 두고 연결해야 해요. 웹이나 폰 앱에서는 내 컴퓨터 폴더에 못 닿아요. (2026년 11월 28일 기준)

권한 모드: 이게 오늘 제일 중요해요. 도움말에 따르면 Pro·Max·Ultra·Team에서는 기본값이 Auto(알아서 허락하고 진행)로 바뀌는 중이에요. 그래서 따로 바꾸지 않으면 Claude가 묻지 않고 움직일 수 있어요. 메시지 상자의 모드 선택에서 Manual로 바꾸고 시작해요. 도움말도 민감한 파일이 걸린 일이면 Manual로 하라고 해요.

무료라면: 3절 2단계의 '계획 받기' 문장은 채팅에서도 돼요. 폴더 안 파일 이름 목록을 붙여 넣고 계획을 받은 뒤, 손으로 옮겨도 시간이 꽤 줄어요.

3. 따라 하기 3단계

1단계. 전용 폴더를 만들고, 민감한 파일은 먼저 빼요

  1. 정리할 폴더(예: 바탕화면)를 통째로 주지 말고, 'Claude 정리함' 같은 새 폴더를 하나 만들어요.
  2. 정리할 파일만 거기로 옮겨요.
  3. 이때 등본, 통장 사본, 계약서, 이력서, 비밀번호 메모는 옮기지 않아요. 내 손으로 다른 곳에 둬요.
  4. 중요한 파일이 섞여 있으면 폴더를 통째로 복사해 둬요.

도움말도 넓게 주지 말고 전용 작업 폴더를 쓰라고, 중요한 파일은 백업하라고, 재무 서류 같은 민감한 파일은 맡기지 말라고 해요. Cowork가 열어 본 파일은 내 컴퓨터가 아니라 Anthropic 서버에서 처리돼요.

이렇게 보이면 성공: 새 폴더 안에 민감한 파일이 하나도 없어요.

2단계. 폴더를 연결하고 계획만 받아요

데스크톱 앱에서 Cowork를 고르고 1단계 폴더를 연결해요. (도움말에는 폴더를 고르는 버튼 이름이 따로 적혀 있지 않아요. 앱에서 폴더를 고르는 곳을 찾아 '정리함' 하나만 골라요.) 그리고 이 문장을 넣어요.

이 폴더를 정리하려고 해. 아직 아무것도 옮기거나 지우지 마.
1) 어떻게 할지 순서대로 (폴더 이름과 어느 파일이 어디로 가는지)
2) 내가 직접 확인해야 할 것
3) 네가 하지 않을 일
4) 이대로 맡길 때 쓸 지시문 한 덩어리 (10줄 안)
짧게.

이렇게 보이면 성공: 파일마다 갈 곳이 적혀 오고, 3번에 '삭제하지 않음'이 들어 있어요. 계획이 마음에 안 들면 여기서 고쳐 달라고 해요. 아직 아무것도 안 움직였으니 몇 번을 고쳐도 괜찮아요.

3단계. 옮기기만 시키고, 되돌리기 목록을 받아요

계획의 4번 지시문 끝에 이 세 줄을 붙여서 넣어요.

삭제는 하지 말고 이동과 이름 바꾸기만 해.
같은 이름이 있으면 덮어쓰지 말고 멈춘 뒤 물어봐.
옮기기 전에 '되돌리기.txt'에 원래 위치 → 새 위치를 한 줄씩 적어 둬.

Manual 모드라면 움직일 때마다 허락 창이 떠요. 처음 몇 개는 하나씩 읽고 Allow를 눌러요. 시키지 않은 파일이나 폴더 밖을 건드리려 하면 Deny를 누르고 멈춰요. 도움말도 말하지 않은 파일에 손대는지 지켜보라고 해요.

이렇게 보이면 성공: 폴더 안에 '되돌리기.txt'가 생기고, 줄 수가 옮긴 파일 수와 같아요.

4. 돌려 본 결과: 지어낸 바탕화면 17개

지어낸 회사원의 바탕화면 파일 17개로 돌려 봤어요. Cowork와 같은 엔진인 Claude Code로 돌렸어요. 회의록 3개(이름이 '회의록_1007', '회의록 1014', '1021회의'로 제각각), '3분기 보고서', '_수정', '_수정 (1)', 스크린샷, 영수증, 견적서, Zoom 설치 파일, 빈 '새 폴더 (2)', 그리고 등본이 섞여 있어요.

계획은 폴더 5개로 왔어요. 회의록, 보고서, 영수증·견적, 개인, 이미지예요. 회의록 이름은 '회의록_MMDD'로 맞추겠다고 했어요.

잘한 것 두 가지가 있었어요.

  • '_수정'과 '_수정 (1)'은 앞부분과 크기가 같았지만, 끝까지 같은지는 비교하지 못했다며 지우지 않고 '중복의심' 폴더로 빼겠다고 했어요. 서랍 속 열쇠를 '모르는 것' 칸에 두는 것과 같아요.
  • Zoom 설치 파일과 빈 폴더는 "지워도 됨" 후보로만 알려 주고 그대로 두겠다고 했어요.

그런데 13강과 같은 일이 또 있었어요. '직접 확인할 것'에 "등본은 주민번호가 있는 문서"라고 적어 놓고도, 계획에서는 등본을 '개인' 폴더로 옮기겠다고 했어요. 위험하다는 걸 알아도 맡긴 폴더 안에 있으면 일감으로 다뤄요. 그래서 1단계 '빼기'가 맨 앞이에요. 저는 등본을 손으로 먼저 빼고 돌렸어요.

옮기기를 시키니 파일 14개를 옮겼고, 지운 파일은 0개였어요. '되돌리기.txt'에는 14줄이 적혔어요. 설치 파일과 빈 폴더는 그대로 남았어요.

하나 놓친 게 있었어요. 계획에서 "1021회의는 날짜만 있고 내용이 없다, 쓰다 만 파일인지 확인하라"고 했는데, 옮길 때는 묻지 않고 '회의록_1021'로 이름을 바꿔 옮겼어요. 지시문에 그렇게 하라고 적혀 있었으니까요. 계획의 '확인할 것'은 지시문을 넣기 전에 내가 답해야 해요. 지시문이 시작되면 Claude는 지시문을 따라요.

5. 학교·회사·생활에서는

  • 학교: 학기 끝난 과제 폴더요. '_최종', '_진짜최종'은 지우지 말고 과목별 '중복의심'으로 빼게 해요. 어느 게 낸 파일인지는 내가 정해요.
  • 회사: 공유 폴더 말고 내 컴퓨터의 내 파일만 해요. 회사 자료를 맡겨도 되는지는 회사 규칙이 먼저예요(10강). 괜찮다면 회의록 이름을 '날짜_주제'로 맞추게 해요. 다음에 찾을 때 시간이 줄어요.
  • 생활: 폰에서 옮긴 사진 폴더를 연·월 폴더로 나누게 해요. 사진 속 사람이나 장소로 나누는 건 하지 않아요. 내 사진을 하나하나 열어 봐야 하는 일이라서요.

6. 막히는 곳, 그리고 왜 그런지

"허락 창이 안 뜨고 그냥 진행돼요."
모드가 Auto거나 Skip이에요. Pro·Max·Ultra·Team은 Auto가 기본값으로 바뀌는 중이라, 처음엔 꼭 Manual로 바꾸고 시작해요. 이미 움직였다면 '되돌리기.txt'를 보고 되돌려 달라고 해요.

"지우지 말랬는데 지울까 봐 불안해요."
도움말에 따르면 Cowork는 파일을 영구로 지우기 전에 꼭 허락 창을 띄워요. 내가 Allow를 눌러야 지워져요. 다만 화면을 직접 조작하는 기능(컴퓨터 사용)에는 이 보호가 적용되지 않는다고 적혀 있어요. 폴더 정리는 파일로만 하게 두면 돼요.

"파일 이름만 보고 엉뚱하게 나눠요."
사진이나 스크린샷은 열어 보기 전엔 뭔지 몰라요. 돌려 본 결과에서도 이미지는 확장자만 보고 나눴다고 했어요. 내용으로 나누고 싶은 파일은 몇 개만 골라 따로 시켜요. 한꺼번에 시키면 사용량도 많이 써요.

"사용량이 금방 닳아요."
여러 단계를 스스로 밟는 일이라 짧은 질문보다 사용량을 더 써요. 설정 > Usage에서 볼 수 있어요. 처음엔 파일 20~30개쯤인 작은 폴더로 해 봐요.

"결과가 마음에 안 들어요."
'되돌리기.txt'를 연결한 채로 "이 목록대로 원래 자리로 되돌려 줘"라고 해요. 이 목록이 없으면 되돌리기가 어려워요. 그래서 3단계에서 옮기기 전에 적게 하는 거예요.

7. 숙제 하나

내 컴퓨터에서 파일이 20~30개쯤인 폴더 하나를 골라요. 유료가 아니라면 파일 이름 목록만 채팅에 붙여 넣어도 돼요. 2단계 문장으로 계획만 받아 보세요.

고른 폴더: ________ / 내 손으로 먼저 뺀 파일: ___개 / 계획의 '확인할 것': ___개

'확인할 것'에 하나씩 답을 적고 나서 3단계로 넘어가요. 그게 오늘 배운 순서예요.

오늘 거 한 장으로

하고 싶은 것어떻게
맡기는 순서빼기 → 계획 받기 → 옮기기만 → 되돌리기 목록
먼저 바꿀 것권한 모드를 Manual로 (Auto가 기본값으로 바뀌는 중)
맡기지 않을 것등본·통장 사본·계약서·이력서·비밀번호 메모
지우기시키지 않아요. '중복의심'·'지워도 됨 후보'로만
계획의 '확인할 것'지시문 넣기 전에 내가 답해요
되돌리기'되돌리기.txt'를 옮기기 전에 적게 해요
