가입이랑 요금제: 무료로 어디까지 되나요?

Claude 무료 요금제로 되는 것과 안 되는 것, 5시간·주간 한도가 도는 방식, 유료로 넘어갈 때를 고르는 기준까지. 공식 요금 페이지로 확인했어요.

돈 얘기부터 할게요. 결제 버튼 앞에서 제일 오래 망설이게 되는 게 이거라서요.
처음 한두 주는 무료로 충분해요. 이 연재 1부(1~8강)도 전부 무료로 따라 할 수 있게 짰어요. 유료는 "무료가 답답하다"는 느낌이 구체적으로 올 때 넘어가면 되는데, 그 느낌이 어떤 모양인지 오늘 같이 볼게요. 그걸 알면 괜히 먼저 결제했다가 한 달 내내 아까워하는 일이 없어요.

1. 가입은 1분이면 돼요

  • claude.ai에 들어가서 구글 계정이나 이메일로 가입해요.
  • 처음에 이름이랑 몇 가지를 물어보는데, 나중에 설정에서 다 바꿀 수 있어요. 고민하지 말고 넘겨도 돼요.
  • 이렇게 보이면 성공: 가운데 인사말, 아래 입력창, 왼쪽에 지난 채팅 목록 칸.
  • 폰 앱도 같은 계정으로 로그인하면 채팅이 그대로 이어져요. 출근길에 폰으로 시작한 정리를 회사 컴퓨터에서 이어 쓸 수 있어요.

2. 요금제는 네 가지예요 (개인용)

공식 요금 페이지(claude.com/pricing)에 나온 그대로 옮겼어요. 가격은 미국 달러 기준이고, 세금은 빠져 있어요.

요금제한 달한 줄로
Free0원5시간·일주일 단위로 쓸 수 있는 양이 정해져 있어요
Pro20달러 (1년치 200달러를 한 번에 내면 월 17달러꼴)무료보다 많이 쓰고, 상위 모델·Claude Code 등이 더해져요
Max100달러5시간·일주일 사용량이 Pro의 5배예요
Ultra200달러일주일 사용량이 Pro의 10배, 5시간 한도는 없어요(인증된 계정)

한국에서 결제하면 원화 같은 지역 통화로 보일 때가 있고, 세금이 붙는 방식도 지역마다 달라요. 공식 도움말에도 "지역마다 다르다"고만 적혀 있어요. 정확한 원화 금액은 결제 화면에서 한 번 보고 정하세요.

10·20대에게 월 20달러는 작은 돈이 아니에요. 밥 몇 끼 값이죠. 그래서 무료로 충분히 써 본 다음에 정하는 쪽을 권해요.

3. 무료로 되는 것

생각보다 많아요. 공식 요금표 기준으로 무료에서도 이런 게 돼요.

  • 웹·데스크톱 앱·폰 앱에서 채팅
  • 웹 검색 (최신 정보를 찾아서 답해 줘요)
  • 파일 만들기·코드 실행 (표나 문서를 파일로 만들어 줘요)
  • 아티팩트 (대화 옆에 결과물을 따로 띄워 주는 창이에요. 3강에서 볼게요)
  • 프로젝트 최대 5개 (같은 자료·지침을 매번 안 붙여도 되는 방이에요. 9강에서)
  • 기억(메모리), 시크릿 채팅
  • 커넥터, Skills, 음성 모드
  • Claude Design, 슬라이드, 문서 만들기

모델은 Sonnet과 Haiku만 쓸 수 있어요. 상위 모델(Opus)은 유료부터예요.

"무료 모델이면 결과가 확 떨어지는 거 아니에요?" 하고 걱정될 수 있어요. 저희가 인스타 카드에 쓴 문장들을 무료 모델(Sonnet)로 다시 돌려 봤더니 대부분 같은 모양으로 나왔어요. 회의 메모 표, 긴 문서 요약, 인수인계 정리는 거의 차이가 없었고, 점수를 매기는 일에서 점수가 1점씩 다르게 나오는 정도였어요. (2026년 11월 15일, 저희가 직접 돌린 기록) 그러니 이번 주 일은 무료로 시작해도 손해 볼 게 없어요.

4. 무료로 안 되는 것

공식 요금표에서 Free 칸이 "No"인 것들이에요.

  • Claude Code (6부에서 다룰 자동화 도구)
  • Claude in Chrome (브라우저를 대신 조작해요)
  • Research (여러 자료를 오래 찾아서 보고서로 묶어 줘요)
  • 일 맡겨 두고 예약하기
  • 상위 모델(Opus), 사람 몰릴 때 우선 접속

정리하면 대화로 하는 일은 무료로 거의 다 되고, Claude가 혼자 오래 돌아가는 일은 유료예요. 이 연재도 1~2부는 대화로 하는 일이라 무료로 충분해요. 6부 Claude Code부터는 유료가 필요한데, 그 강에 가면 다시 알려 드릴게요.

5. 한도는 어떻게 도나요?

무료로 쓰다 보면 언젠가 "사용 한도에 도달했어요" 같은 안내를 보게 돼요. 놀라지 마세요. 고장이 아니라 정해진 양을 다 쓴 거예요.

공식 설명은 이래요.

  • 쓸 수 있는 양이 5시간 단위, 그리고 일주일 단위로 정해져 있어요.
  • 일주일 한도는 계정마다 정해진 시각에 다시 차요.
  • 지금 얼마나 썼는지는 설정 > 사용량에서 막대로 보여요. "현재 세션"이 5시간짜리, "주간 한도"가 일주일짜리예요.

그리고 같은 한 번이라도 무거운 게 있고 가벼운 게 있어요. 공식 도움말이 꼽는 무거운 것들은 이래요.

  • 긴 메시지, 큰 파일
  • 오래 이어진 대화 (대화가 길수록 매번 앞 내용을 다시 읽거든요)
  • 웹 검색 같은 도구 쓰기
  • 상위 모델

50쪽 PDF를 붙여 놓고 한 채팅에서 질문을 20번 이어 하면, 짧은 질문 20번보다 훨씬 빨리 차요. 마감 전날 밤에 한도가 막히는 일은 대개 이렇게 생겨요.

자주 쓰는 자료는 프로젝트에
매주 붙이는 회사 소개나 과제 안내문은 프로젝트에 한 번 넣어 두세요. 공식 도움말 말로는 다시 쓸 때 한도에 덜 잡혀요. 무료도 프로젝트 5개까지 돼요.

7. 유료로 넘어갈 때 고르는 기준

아래 중 두 개 이상이 매주 생기면, 그때 Pro를 고민해도 늦지 않아요.

  • 한도에 걸려서 하던 일을 몇 시간 기다린 적이 한 주에 두 번 넘어요
  • Claude Code나 예약 실행처럼 혼자 돌아가는 일을 해 보고 싶어요
  • 무료 모델 답이 계속 아쉬운 일이 있어요 (같은 문장을 두 번 돌려도 둘 다 별로)
  • 프로젝트가 5개로 모자라요

한 개뿐이면 아직은 6절의 아껴 쓰는 법으로 버틸 수 있어요. 한 달만 결제해 보고 아니다 싶으면 해지하는 방법도 있고요.

8. 막히는 곳, 그리고 왜 그런지

"가입했는데 상위 모델이 안 보여요."
무료는 Sonnet·Haiku만 돼서 그래요. 정상이에요.

"한도 걸렸는데 언제 풀려요?"
설정 > 사용량에 다시 차는 시각이 나와요. 5시간짜리면 길어야 몇 시간이에요. 그 사이엔 손으로 할 일을 먼저 하면 돼요.

"어제는 많이 썼는데 오늘은 금방 차요."
양은 횟수가 아니라 무게로 세요. 오늘 큰 파일을 붙였거나, 대화를 길게 이어 갔거나, 웹 검색을 많이 켰을 거예요.

"요금표에 Cowork가 안 보여요."
저희가 11월 17일에 본 요금표 비교표에는 Cowork가 따로 나와 있지 않았어요. 3부에서 Cowork를 다룰 때 다시 확인해서 알려 드릴게요.

9. 숙제 하나

설정 > 사용량을 열어서 막대 두 개(현재 세션, 주간 한도)를 한 번 봐 두세요. 이번 주에 한도에 걸린 적이 있다면, 그때 무슨 일을 하고 있었는지 한 줄 적어 두세요.

○월 ○일, ______ 하다가 걸림.

두세 줄만 쌓여도 유료가 필요한지 아닌지가 보여요. 감으로 결제하지 않게 돼요.
